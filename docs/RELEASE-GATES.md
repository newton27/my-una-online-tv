# Release gates

1. Confirm the module's installer follows actual UNA 14 and UNA 15 native contracts.
2. Run install, disable/enable, uninstall and upgrade workflows on disposable test sites.
3. Build independent Studio admin pages, viewer and guarded catalog synchronization.
4. Verify permission and CSRF checks, SSRF protections, rate limits and no automatic deletions.
5. Implement read-only migration from legacy Modzzz channel data with backups and reconciliation.
6. Create original branded media artwork; validate Marketplace listing and download packaging.
7. Run source license audit, PHP syntax and runtime regression tests; publish immutable checksum-verified release.
8. Keep this independent repository free and without activation requirements.
